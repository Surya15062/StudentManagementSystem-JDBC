# 🎓 Student Management System (JDBC + MySQL)

A console-based Student Management System developed using **Core Java, JDBC, and MySQL**.  
This project follows the **DAO (Data Access Object) architecture** to maintain clean separation between business logic and database operations.

---

## 🚀 Features

- ➕ Add Student
- 📋 View All Students
- ✏️ Update Student Details
- ❌ Delete Student
- 🔗 MySQL Database Integration
- 🧱 DAO Architecture Implementation
- 🛡 Exception Handling using `throws`

---

## 🛠 Technologies Used

- Java (JDK 17)
- JDBC
- MySQL
- IntelliJ IDEA
- Git & GitHub
